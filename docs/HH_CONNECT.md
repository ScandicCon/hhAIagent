# hh.ru API — актуально с 2025

## Ответ поддержки hh.ru

С **декабря 2024** токен **соискателя** (OAuth пользователя) **больше не поддерживается** для API.

**Недоступно:**
- `GET /resumes/mine` — список резюме
- отклики через API (`/negotiations`)
- синхронизация резюме и автоотклик из бота

**Доступно** — только **токен приложения** (Client ID + Secret):
- поиск вакансий
- просмотр вакансии
- [документация](https://api.hh.ru/openapi/redoc#tag/Avtorizaciya-prilozheniya)

## Как работает HH AI Agent сейчас

| Функция | Как |
|---------|-----|
| Резюме | Текстом в боте (`/start` → отправить резюме) |
| Поиск вакансий | API приложения ✅ |
| AI match + письмо | ✅ |
| Отклик | Вручную: «Открыть на hh.ru» → вставить письмо из бота |

Кнопки «Подключить hh.ru» / «Синхронизировать резюме» / «Автоотклик» в боте отключены — API hh не даёт это соискателю.

## .env (поиск вакансий)

```env
HH_CLIENT_ID=...
HH_CLIENT_SECRET=...
HH_USER_AGENT=hh-ai-agent/1.0 (your@email.com)
```

OAuth Redirect URI для соискателя **не нужен** для текущего функционала.
