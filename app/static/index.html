Как принимаются платежи

Сайт информирует о сервисе и ценах. Оплата — за цифровую подписку Pro в Telegram-боте через ЮKassa. Корзина на сайте не используется: товар один (тариф Pro), выбор — в боте.

1

Пользователь открывает Telegram-бот @HHSearchVacanciesBot и нажимает «Купить Pro» (490 ₽).

2

Бот создаёт платёж через API ЮKassa и показывает кнопку «Оплатить 490 ₽» — переход на защищённую страницу ЮKassa.

3

Клиент оплачивает картой или СБП на стороне ЮKassa. Сайт api.hhsearch.ru не хранит данные карт.

4

После успешной оплаты ЮKassa отправляет webhook на наш сервер; тариф Pro активируется в боте автоматически.

Техническая интеграция: API ЮKassa (создание платежа), HTTP-уведомление /payments/yookassa/webhook. Возврат в бот после оплаты — по ссылке Telegram.

AI — помощник для поиска работы, не гарантия трудоустройства.

Резюме обрабатывается для подбора вакансий (152-ФЗ).
